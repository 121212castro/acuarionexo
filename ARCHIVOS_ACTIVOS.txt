REGLAS OBLIGATORIAS
- app.js es el unico arranque funcional de la app.
- index.html solo carga Supabase, config.js, app.js y update-manager.js.
- Ningun archivo externo debe redefinir window.dashboard, window.biblioteca, window.fotos, window.pars, window.panel, window.microfauna o rutas principales.
- Si una funcionalidad hace falta, se integra primero en app.js con una unica fuente de estado.
- No usar routers dinamicos.
- No usar bloques inline grandes dentro de index.html.
- app-version.json debe tener el mismo build que window.ACUARIONEXO_BUILD.
- El contenedor mobile-wrapper/ no debe duplicar HTML de produccion: carga la URL oficial.
