REGLAS OBLIGATORIAS
- app.js es el nucleo coordinador, no un contenedor de pantallas.
- index.html solo carga el nucleo web activo y CDNs necesarios.
- La app movil copia el nucleo web activo a www/ con npm run mobile:prepare.
- No usar server.url en Capacitor: la app debe llevar los archivos dentro.
- Solo los modulos oficiales pueden exponer funciones window.* para botones inline.
- Si una funcionalidad hace falta, se integra en su modulo de dominio con una unica fuente de estado en window.ANX.
- src/auth/auth.js se carga al final porque ejecuta boot().
- No usar routers dinamicos.
- No usar bloques inline grandes dentro de index.html.
- No volver a meter funcionalidades grandes en app.js.
- app-version.json debe tener el mismo build que window.ACUARIONEXO_BUILD.
- No conservar wrappers, motores antiguos ni copias paralelas dentro de main.
