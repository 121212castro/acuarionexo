# AcuarioNexo · Panel Admin

## Objetivo
Centralizar herramientas de administración sin gastar créditos IA innecesariamente.

## Módulos

### Studio Fotos
- subir foto
- fondo oficial
- zoom
- recorte
- miniatura
- exportar

### Fichas
- borradores
- revisión
- publicadas
- ocultas testers

### Gemini Import
- generar prompt
- pegar respuesta Gemini
- validar ficha
- guardar JSON

### Testers
- reportes
- errores
- rendimiento
- actividad

### IA
- activar/desactivar
- límites
- caché
- uso créditos

## Flujo
1. Crear foto
2. Crear ficha
3. Revisar
4. Publicar
5. AcuarioNexo consume datos publicados
